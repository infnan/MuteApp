# 静音开关

Android 7.0 及以上（minSdk 24）的独立原生应用，无第三方运行时依赖。
包名：`com.example.mutetoggle`；版本：1.1。

## 使用

1. 安装或覆盖安装 `dist/MuteToggle.apk`，启动“静音开关”。直接尝试 Android 的静音切换，不再以勿扰权限查询结果作为启动前提。
2. 正常响铃状态下启动：调用 Android `AudioManager.setRingerMode(RINGER_MODE_SILENT)`，确认状态后在同一回调中显示 Toast：“已开启静音”，并振动 0.5 秒。不播放提示音。
3. 静音或振动状态下启动：切换至 `RINGER_MODE_NORMAL`，恢复零音量，确认后 Toast：“已关闭静音”，并播放系统音效 `zhytera`；找不到或无法播放时使用极短 beep。
4. 只有切换 API 确实抛出权限异常、且等待核验后仍未切换成功时，才考虑授权引导。如果系统报告已经授权，则仅提示实际操作失败；否则最多自动打开一次系统授权页，之后即使未授权或授权被撤销也不反复跳转，只用 Toast 提示手动授权。授权页返回后再次启动应用。

没有应用操作页面、常驻通知或后台服务；仅使用透明入口 Activity，不出现在最近任务中。透明入口短暂保留以完成核验、振动或提示音，随后退出。处理中的重复启动合并，不重复翻转状态；下次启动重新读取系统状态，不依赖应用保存的开关。仅保存“已引导授权”标记。

## 状态核验

不再以切换后 250 毫秒的一次读数判定失败。现在每隔 250 毫秒检查，最多等待 2 秒，同时参考系统铃声模式查询与公开的铃声模式粘性广播；下次启动也参考该广播，兼容查询值和广播更新不同步的情况。API 报错但系统实际已达到目标模式时，按成功处理，不跳转授权页。API 没有报错但始终没有确认到目标模式时，只提示“已发送静音切换指令，系统尚未确认状态”，不把未确认误报为切换失败或冒充已成功。振动或提示音错误不会把已经确认成功的静音切换改报为失败。

## 音量恢复

- 先退出静音，等待 250 毫秒，再逐项读取音量；随后重试并再次核验，避免固件延迟恢复音量。
- 覆盖六种 Android 标准音量流：铃声、通知、媒体、闹钟、通话、系统。包含常见的媒体／通话／铃声通知／闹钟四类；部分固件会关联铃声、通知和系统音量。
- **仅将当前为 0 的音量设置为 3**，非零值保持不变。不把所有音量强制统一为 3；最大档位不足 3 时使用设备允许的最高档，最低档限制也予以遵守。不弹出系统音量面板。
- 如果设置被系统拒绝，或核验后仍有零音量，会提示“已关闭静音，但部分音量未能恢复，请检查系统音量”，并在 `adb logcat -s MuteToggle` 中记录对应音量流。
- 仅使用 Android 的原生静音模式，不额外将媒体、闹钟和通话音量清零；这些声音在静音期间是否继续响，由目标固件的静音规则决定。
- 已由用户确认：目标机器的四类音量为通话、铃声、媒体、闹钟；无线电通信使用通话音量。四类默认不同步，用户可以在系统中设置同步。本次不据此更改既有音量恢复逻辑、不调整同步设置。
- 用户已确认原生静音不会让无线电通信静音，且这符合预期。本应用保留这一行为，不为无线电另行静音、不在开启静音时将通话或其他音量清零、不增加厂商私有控制。

## 恢复提示音

在系统内置音频目录中按标题或文件名查找 `zhytera`（忽略大小写及文件扩展名），用通知音量通道播放，最多约 2 秒。不改系统默认通知音设置。不再使用其他默认铃声或闹钟音替代。

找不到 `zhytera`、系统目录不可读取、准备超时或播放失败时，使用 Android `ToneGenerator` 生成一次极短的系统 beep（时长上限 120 毫秒），不需要额外音频文件或存储授权。不常驻后台，不关闭用户另行设置的勿扰模式，不绕过音频路由和设备策略，因此独立勿扰规则、耳机或蓝牙路由仍可能影响实际听感。

## 构建

需要 JDK 17 或 21、Android SDK Platform 35、Build Tools 35.0.0。

```powershell
.\tools\build-apk.ps1
```

默认只读复用相邻 `HotspotApp/.tools/android-sdk`，也可传入 `-SdkPath`、`-JdkPath`。脚本自动处理中文路径，输出签名 APK 到 `dist/MuteToggle.apk`，使用本项目 `.tools/mute-debug.keystore`，后续更新须保留此签名密钥。此签名为本地测试用途，非应用商店发布证书。

也提供标准 Gradle 工程。配置 `local.properties` 中的 `sdk.dir` 后，可运行 `gradlew.bat :app:assembleDebug :app:lintDebug`。Gradle 默认调试签名与构建脚本签名可能不同，覆盖安装请始终使用同一种构建方式。

## 真机验收

- 未授权但固件允许切换：直接完成切换，不打开授权页；系统确实拒绝且状态未改变时只自动引导一次，再次启动不重复打开授权页。
- 正常模式：启动后变静音，显示“已开启静音”时同时振动 0.5 秒，不播放提示音。
- 静音／振动模式：启动后恢复响铃、显示“已关闭静音”，优先播放 `zhytera`，不存在时只播放一声极短 beep。
- 在系统设置分别将四种音量设为 0，恢复后确认其为 3；将其设置为 1、2、5 等非零值后确认不被覆盖。
- 使用设备物理旋钮、PTT、耳机及蓝牙分别验证；确认无线电通信不受本应用开启原生静音的额外干预。
- 连续触发、旋转屏幕、从最近任务重建或撤销授权，不应重复切换或误报成功。
